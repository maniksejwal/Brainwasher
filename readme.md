Multi-Agent Reconciliation System - JS Prototype v2

This project is a minimal, command-line prototype of the multi-agent system described in the invention disclosure, built with Node.js. It demonstrates the core intellectual property: a system that uses a network of AI agents to reconcile conflicting information from multiple human users (e.g., a patient and a caregiver).

Version 2 adds a persistent SQLite database and generative AI replies from the personal agent.
Core IP Demonstrated

    Multi-Agent Reconciliation Engine: The Orchestrator receives reports, identifies conflicts, and stores facts in a persistent database.

    Privacy Discriminator Agent: The Orchestrator uses the Gemini API to check messages for sensitive information.

    Personal Agent Replies: The system generates a unique, empathetic AI response back to each user after they send a message.

    Care Circle Communication: The system routes messages and alerts between users in the "care circle".

Architecture

    orchestrator.js: A Node.js/Express server that acts as the brain, now with generative reply capabilities.

    client.js: A Node.js command-line interface to simulate different users.

    database.js: A new module to manage the SQLite database connection and queries.

    carecircle.db: The SQLite database file that will be automatically created.

How to Run the Prototype

    Install Dependencies:

        Make sure you have Node.js and npm installed.

        Run the following command in your project directory:

    npm install

    Set Up API Key:

        Create a file named .env if you haven't already.

        Add your Gemini API key to it: GEMINI_API_KEY="YOUR_API_KEY_HERE"

    Run the Orchestrator:

        Open a terminal window and run the server. This terminal acts as the "Doctor's View".

    node orchestrator.js

        You will see a message confirming the database is connected.

    Run the Clients:

        Open two new, separate terminal windows. In each one, run:

    node client.js

        Enter patient in one and caregiver in the other.

Example Scenario to Test New Features

    Send a Message: In the patient's terminal, type: I took my medicine this morning.

    Receive a Personal Reply: You will immediately see a supportive reply generated by the AI, like: [personal-agent says]: That's great to hear! Keeping on track is a big step. This message will not appear for the caregiver.

    Test Conflict: Have the caregiver report a conflicting fact. The conflict will be detected and logged as before.

    Restart the Orchestrator: Stop the orchestrator (Ctrl+C) and restart it (node orchestrator.js). The facts you've entered will still be there, demonstrating database persistence.
