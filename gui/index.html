How to Use Care Circles

What is this?

A multi-agent system where each person has their own AI assistant. Agents coordinate care while respecting privacy boundaries.

Available Commands

/care username as relationship - Add caregiver (e.g., /care mom as mother)
/doc username [as specialty] - Add doctor (e.g., /doc dr_smith as Cardiology)
/circle - Show circle members and their roles
/switch username - Switch to another circle (role changes automatically)
/mycircles - Show all your care circles
/patients - Show all your patients (for doctors)
/feedback +1|-1 "comment" - Rate interaction (e.g., /feedback +1 "Great!")
/consent username level - Set consent (none/limited/full)
Or use the dropdown in Circle view

How Roles Work

Your role changes automatically based on which circle you're in:

  • In your own circle: You're the patient
  • When added to someone else's circle: You're a caregiver or doctor
  • Use /switch username to change circles (your role updates automatically)
  • Check your current role in the header badge and browser tab title

Doctor-Specific Commands

If you're a doctor, first set your specialty:

  • /spec Cardiology - Set your specialty (unlocks doctor features)
  • /log "note" - Add confidential notes to patient record
  • /order "test/medication" - Log orders
  • /agent ask patient "topic" - Delegate questions to patient's agent

Keyboard Shortcuts

Ctrl+F - Quick feedback

Terminology

Interaction: Single message exchange (your message + agent response)

Conversation: Full chat session (multiple interactions grouped together)
